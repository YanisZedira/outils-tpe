Générateur de données structurées pour entreprise locale

Remplissez la fiche de votre entreprise. L’outil produit le code JSON-LD de type LocalBusiness, que Google lit pour comprendre qui vous êtes, où vous travaillez et quand vous êtes ouvert.


    
Tester dans l'outil de Google

    
Tout se passe dans votre navigateur : rien n'est envoyé ni enregistré sur un serveur.

  


  

    
À quoi servent ces données

    
Les données structurées sont un bloc de code invisible pour le visiteur, écrit dans un vocabulaire commun aux moteurs de recherche (schema.org). Elles disent sans ambiguïté le nom de l'entreprise, son métier, son adresse, ses horaires et ses zones d'intervention. Google s'en sert pour relier votre site à votre fiche d'établissement, et les assistants IA pour citer vos coordonnées sans les deviner.

Trois règles pour ne pas se tromper

    
    
      
  • Les mêmes informations que sur votre fiche Google, au caractère près : nom, téléphone, adresse.
    • 
      
  • Le type le plus précis. « Plombier » vaut mieux que « Entreprise locale ».
    • 
      
  • Aucune note d'avis ajoutée à la main. Google ignore les étoiles qu'une entreprise s'attribue sur son propre site, et peut le sanctionner.
    • 
    

  


  

    
Questions fréquentes

    
Les données structurées améliorent-elles le classement Google ?

    
Elles ne font pas monter une page à elles seules. Elles aident Google à comprendre l’entreprise et à l’associer à sa fiche d’établissement, et rendent possibles certains affichages enrichis. C’est une base à poser, pas un levier isolé.

    
Faut-il mettre ce code sur toutes les pages ?

    
La page d’accueil ou la page de contact suffit pour décrire l’entreprise. Si vous avez plusieurs établissements, placez un bloc par établissement sur la page qui lui est dédiée.

    
Que faire si je n’ai pas de local ouvert au public ?

    
Cochez la case de déplacement chez les clients : la rue n’est pas publiée, seules la ville et les zones desservies le sont. C’est le cas des artisans et des prestataires à domicile.
