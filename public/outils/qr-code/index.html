Générateur de QR code, sans inscription

Créez un QR code pour un lien, un réseau Wi-Fi ou une carte de contact. Le code est fabriqué dans votre navigateur : il ne passe par aucun service et ne peut donc pas expirer.

Tout se passe dans votre navigateur : rien n'est envoyé ni enregistré sur un serveur.

Comment utiliser votre QR code

Un QR code est une image qui contient un texte. Quand ce texte est un lien, le téléphone propose de l'ouvrir. Le code produit ici est dit statique : le contenu est inscrit dans l'image elle-même, sans redirection par un service tiers. Il fonctionne tant que le lien fonctionne.

  • Imprimez-le assez grand. Comptez 2 cm de côté au minimum pour une lecture à la main, et environ un dixième de la distance de lecture pour une affiche.
  • Gardez la marge blanche. Sans elle, beaucoup de téléphones ne détectent pas le code.
  • Testez avant d'imprimer, avec deux téléphones différents.
  • Dites ce qu'il ouvre. « Scannez pour laisser un avis » est scanné plus souvent qu'un code seul.

Le format SVG reste net à toutes les tailles : c'est celui à donner à un imprimeur. Le PNG convient pour un écran ou un document.

Questions fréquentes

Ce QR code a-t-il une date d’expiration ?

Non. Le lien est inscrit directement dans l’image, sans redirection. Le code reste lisible tant que la page ou le réseau qu’il désigne existe.

Peut-on modifier le lien après impression ?

Non, c’est la contrepartie d’un code statique. Pour changer la destination sans réimprimer, faites pointer le code vers une adresse de votre propre site, que vous pourrez rediriger.

Comment créer un QR code pour les avis Google ?

Copiez le lien « Demander des avis » depuis votre fiche Google Business Profile, collez-le dans le champ, puis téléchargez le code. Affichez-le en caisse ou sur vos factures.

Le QR code Wi-Fi est-il sûr ?

Il contient le mot de passe en clair : toute personne qui le photographie peut se connecter. Réservez-le à un réseau invité, séparé de celui de l’entreprise.
